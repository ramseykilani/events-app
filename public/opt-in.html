Shared Events — SMS Opt-In

Last updated: September 10, 2026

Operated by Ramsey Kilani.

Ramsey Kilani operates Shared Events, a small app for sharing events person-to-person. Shared Events sends transactional SMS only — never marketing messages. This page documents the two ways a person comes to receive a text from Shared Events and the consent shown at each step.

1. Sign-in verification codes (direct recipient opt-in)

Sign-in is by SMS one-time code — there are no passwords. The recipient opts in directly:

  1. The recipient opens the Shared Events app (sign-in page: https://shared-events.pages.dev/).
  2. They enter their own mobile number in the phone field.
  3. Directly under the Send code button, the screen displays this consent line, with Terms and Privacy policy links beneath it:
By tapping Send code, you agree to receive SMS sign-in codes from Shared Events (one per sign-in). Msg & data rates may apply. Reply STOP to opt out.
  1. Tapping Send code sends exactly one SMS with the sign-in code to the number entered: "Shared Events by Ramsey Kilani: [code] is your sign-in code. Reply STOP to opt out." One code per sign-in — no recurring messages.

2. Event-share notifications (person-to-person)

A signed-in user chooses a specific person — a contact from their address book, or a phone number they type — to tell them about an event. That number receives a single, one-time SMS with the event details, initiated person-to-person by the sharer. Example:

Ramsey Kilani wants to go to "Rooftop Cinema night" with you
Fri, Aug 21, 7:30 PM
https://example.com/tickets

Coming? https://events-reply.pages.dev/?t=abc123

Want to invite your friends to things too? Get the beta: https://events-landing.pages.dev/signup

Reply STOP to unsubscribe.

Frequency, rates, opt out, help

  • Message frequency varies. Texts are occasional and event-driven: one when you request a sign-in code, one when someone shares an event to your number.
  • Message and data rates may apply, depending on your mobile plan.
  • Opt out anytime: reply STOP to any text. The reply is confirmed — "You have successfully been unsubscribed. You will not receive any more messages from this number. Reply START to resubscribe."
  • Help: reply HELP to any text, or email kilani.ramsey@gmail.com.

See also: Terms of Service · Privacy Policy — mobile numbers and messaging consent are never shared with third parties/affiliates for marketing or promotional purposes.
